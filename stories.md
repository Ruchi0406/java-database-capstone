# Smart Clinic - User Stories

## Patient User Stories
1. As a patient, I want to register with my details so that I can book appointments.
2. As a patient, I want to view available doctors so that I can choose a doctor.
3. As a patient, I want to book an appointment so that I can visit the doctor.
4. As a patient, I want to cancel my appointment so that I can reschedule if needed.
5. As a patient, I want to view my appointment history so that I can track my visits.

## Doctor User Stories
1. As a doctor, I want to view my appointments so that I can plan my day.
2. As a doctor, I want to add a prescription so that the patient knows the medicine.
3. As a doctor, I want to view patient details so that I can treat them correctly.
4. As a doctor, I want to update my availability so that patients can book only when I am free.
5.  As a doctor, I want to cancel an appointment so that I can manage emergencies.
  
## Admin User Stories
1. As an admin, I want to add new doctors so that patients can book them.
2. As an admin, I want to view all appointments so that I can manage the clinic.
3. As an admin, I want to remove a doctor so that inactive doctors are not shown.
4. As an admin, I want to view all patients so that I can manage patient records.
5. As an admin, I want to view all doctors so that I can manage doctor records.
