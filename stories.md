# Smart Clinic - User Stories

## Patient Stories
1. As a patient, I want to register with my details so that I can book appointments.
2. As a patient, I want to view available doctors so that I can choose a doctor.
3. As a patient, I want to book an appointment so that I can visit the doctor.
4. As a patient, I want to cancel my appointment so that I can reschedule if needed.

## Doctor Stories
5. As a doctor, I want to view my appointments so that I can plan my day.
6. As a doctor, I want to add a prescription so that the patient knows the medicine.

## Admin Stories
7. As an admin, I want to add new doctors so that patients can book them.
8. As an admin, I want to view all appointments so that I can manage the clinic.
